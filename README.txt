SAHAN BANDARA - CINEMATIC PORTFOLIO

Files in this folder:
- index.html              Main responsive portfolio website
- sahan-portrait.jpg      Your original portrait used in the interactive 3D effect
- Sahan_Bandara_CV.pdf    Downloadable CV linked from the website

How to preview:
1. Keep all three files in the same folder.
2. Open index.html in a modern browser (Chrome or Edge recommended).
3. The splash screen types the intro automatically. Click "Enter portfolio" to skip it.
4. Move the cursor over the portrait artifact to tilt the object and animate its mesh.
5. Scroll through the education roadmap to move the car along the road.

For hosting, upload all three files to the same directory on your hosting provider.
The site uses local HTML/CSS/JavaScript and the bundled portrait; no build step is required.
